# EazyPG---PG-Paying-Guest-Management-System
EazyPG – PG Management System: Built a full-stack PG management platform using Java, Spring Boot, Spring Cloud, React, Redux Toolkit, MySQL, and JWT. Developed microservices for authentication, users, properties, bookings, and payments, with secure JWT-based access, REST APIs, role-based dashboards, and advanced PG search with filters.
